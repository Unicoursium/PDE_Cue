Place kiosk image assets in this folder with these filenames:

- `cue_logo_dark.png`: white Cue logo for the clock screen.
- `cue_logo_light.png`: black Cue logo for the game select screen.
- `clock_font.ttf`: optional custom font used for the clock digits.
- `clock_font_regular.ttf`: generated Regular weight used by the kiosk.
- `game_tug_of_war.png`: main artwork for Tug of War.
- `game_hot_potato.png`: main artwork for Hot Potato.
- `game_reaction_time.png`: main artwork for Reaction Time.
- `game_five_second_reaction.png`: full-screen selection page for 5 Second Reaction.
- `game_darts.png`: full-screen selection page for Darts.
- `game_truth_or_dare.png`: full-screen selection page for Truth or Dare.
- `game_exit.png`: full-screen page for returning to the clock.
- `rules_tug_of_war.png`: rules page shown before Tug of War starts.
- `rules_hot_potato.png`: rules page shown before Hot Potato starts.
- `rules_reaction_time.png`: rules page shown before Reaction Time starts.
- `rules_five_second_reaction.png`: rules page shown before 5 Second Reaction starts.
- `rules_darts.png`: rules page shown before Darts starts.
- `rules_truth_or_dare.png`: rules page shown before Truth or Dare starts.

Recommended canvas size for all game selection pages: 640 x 480 px.
The kiosk will still run if any image is missing; it will draw a fallback card.
